# Braintune — Kids Focus + Learning Web Game

Braintune is a playful, offline-capable educational focus and learning web app designed for children ages 4–8. It combines essential early-learning concepts (memory, letters & phonics, numbers & counting, colors & shapes, and math & logic) with focus and attention training.

---

## Features

- **Child Profiles**: Create, switch, edit, and delete profiles with fun animal avatars, stars, coins, XP levels, daily streaks, and 12 achievement badges.
- **5 Interactive Mini-Games** (20 difficulty levels each, across Basic, Normal, Hard, and Very Hard modes):
  - **Memory Match & Tap**: Peek-and-match card pairs up to 12 pairs, plus Spot the Target attention mode.
  - **Letters & Phonics**: Uppercase/lowercase letter matching and fill-in-the-blank spelling puzzles.
  - **Numbers & Counting**: Visual counting and number pattern sequences up to 100.
  - **Colors & Shapes**: Color identification, shape + color matching, and AB/ABC pattern completion.
  - **Math & Logic**: Addition, subtraction, multiplication, division, parentheses, and mixed operations.
- **Parent Zone**: Protected by a math parental gate, offering child performance reports, sound/music/voice toggles, and accessibility options (High Contrast, Reduced Motion, Larger Text).

## Local Development

### Prerequisites
- Node.js (>= 22.0.0)
- npm

### Install & Run
```bash
npm install
npm run dev
```
The Vite dev server runs on `http://0.0.0.0:3000`.

### Build & Typecheck
```bash
npm run lint
npm run build
```
